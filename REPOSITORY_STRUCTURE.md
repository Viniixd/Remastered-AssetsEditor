## Overview Summary

- **Number of folders:** 7 (including the project root and excluding Git's internal subdirectories).
- **Number of files:** 68 (excluding files under `.git/`).
- **Key modules and roles:**
  - `Assets Editor/` — Main WPF application encompassing XAML views, code-behind logic, and utilities for Tibia asset editing.
  - `Assets Editor/OTB/` — Binary tree parsers and writers enabling OTB asset import/export.
  - `Assets Editor/OBD/` — Decoders for OBD binary descriptions referenced by the editors.
  - `Assets Editor/images_generator/` — PHP-based tooling for producing sprite imagery and web previews complementing the desktop editor.
  - `Assets Editor/Resources/` — Embedded visual assets (PNGs, GIFs, icons) surfaced in the UI and documentation.
